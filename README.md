# The Day We Found Our Way Back 🖤💙♾️

> *“People who once talked about everything can suddenly go 390 days without saying a word. And then, the silence breaks, and starlight returns.”*

A bespoke, interactive celestial web experience crafted for **Depression Buddy (Lavi / Lavanya)** to celebrate finding our way back after 390 days of silence.

---

## 🌌 Chapters & Features

1. **Chapter 1: The Cosmic Timeline & Homecoming**
   - Live real-time reunion counter.
   - Cinematic typewriter thought lines and interactive starfield canvas.
   - Ambient soundscape engine with procedural harmonic chime synthesis.

2. **Chapter 2: The Buddy Surprise Vault**
   - Interactive celestial keypad and riddle cipher.
   - Real-time password validation with gentle guidance modal.

3. **Chapter 3: The Friendship Arcade (7 Games)**
   - **Game 1: Tic-Tac-Toe** (Lavi 💙 vs Yadav 🖤 with playful AI and custom scoreboards).
   - **Game 2: The Big Celestial Word Finder** (12x12 grid with 144 tiles and 12 hidden memories).
   - **Game 3: Pop the Balloon** (5 glowing balloons revealing heartfelt thoughts).
   - **Game 4: Spin Wheel** (High-DPI canvas wheel of connection sentiments).
   - **Game 5: Mystery Box** (Celestial boxes with the Golden Keepsake win).
   - **Game 6: Photo Memory Match** (20-card matching challenge featuring 10 crystal-clear portraits).
   - **Game 7: Heart Catcher** (Interactive canvas saucer paddle catching falling starlight and hearts).

4. **Chapter 4: The Very Fancy Wax-Sealed Letter**
   - Interactive cracking wax seal animation with custom audio.
   - Full-screen reading mode with floating particle reactions (petals, blue hearts, virtual hugs).

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript**: Zero heavy framework overhead; silky 60fps canvas animations.
- **Tailwind CSS & Vanilla CSS Design System**: Glassmorphism, liquid-glass glows, and responsive typography.
- **Web Audio API**: Procedural synthesized chords, ticks, pops, and arpeggios.
- **Hosting-Ready**: Optimized for GitHub Pages, Netlify, and Vercel.
